# RealEstate World – Prototype District

## Run locally
    npm install
    npm start
Open http://localhost:3000 in two browser tabs. You should see both agents.

## Deploy (free) on Render
1. Push this folder to a GitHub repo.
2. render.com -> New -> Web Service -> pick the repo.
3. Build command: npm install    Start command: npm start
4. Open the URL Render gives you. That URL is your contest "Project link".
